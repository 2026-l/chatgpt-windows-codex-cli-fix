# Contributing

Thanks for helping improve this troubleshooting guide.

When reporting a result, please include:

- Windows version and architecture;
- desktop app version, if known;
- Codex CLI version;
- the exact error message (with personal data removed);
- whether `Test-Path $env:CODEX_CLI_PATH` returns `True`;
- whether `& $env:CODEX_CLI_PATH --version` runs successfully.

Do not post secrets, private file paths, account identifiers, or unredacted screenshots.
