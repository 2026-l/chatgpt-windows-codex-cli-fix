# Security and privacy

This project does not require API keys, passwords, cookies, or account tokens.

If a troubleshooting step asks you to expose or commit a secret, stop and do not do it.

Before opening an issue or sharing a screenshot, redact:

- Windows usernames and private paths;
- email addresses and account identifiers;
- API keys, tokens, cookies, and session data;
- private school/work file names.
